## 这个知识点在解决什么

- 看懂圆上的横坐标就是 `cos(x)`
- 看懂 `cos(x)` 为什么从最高点开始
- 会用左右半圆判断余弦值的正负
- 看懂它和 `sin(x)` 的关键点差异与平移关系

## 单元定位

学完 `sin(x)` 后，再看 `cos(x)` 不需要重学一套系统。单位圆上的点仍是同一个点，只是观察方向从“上下高度”换成了“左右位置”。

在交互区拖动角度时，重点观察蓝色横投影：圆上点位于 y 轴右侧时，横坐标为正；位于 y 轴左侧时，横坐标为负。右侧图像正是在按角度顺序记录这个横坐标。

## 和正弦放在一起看最清楚

- `cos(x)` 从 1 起步
  因为角度从 0 开始时，单位圆上的点就在最右端，横坐标正好是 1。
- 余弦看的是 `横坐标`
  所以它和正弦的区别，不是“又多了一条曲线”，而是观察同一个圆上不同方向的投影。
- 一个周期同样是 `2π`
  转满一圈以后，横坐标变化模式也会完整重复。

## 五个关键点和正弦逐项对照

- `x = 0`：横坐标为 1，所以余弦从最大值开始。
- `x = π/2`：点在 y 轴上，横坐标为 0。
- `x = π`：点在最左端，横坐标为 -1。
- `x = 3π/2`：点再次落在 y 轴上，横坐标为 0。
- `x = 2π`：回到最右端，横坐标恢复为 1。

正弦的五点顺序是 `0，1，0，-1，0`；余弦的五点顺序是 `1，0，-1，0，1`。不要孤立背两串数，要回到“纵坐标”和“横坐标”理解。

## 余弦正负看左右半圆

- 第一、第四象限位于 y 轴右侧，所以 `cos x > 0`。
- 第二、第三象限位于 y 轴左侧，所以 `cos x < 0`。
- 终边落在 y 轴上时，横坐标为 0，所以余弦值为 0。
- 例如 120° 在第二象限，点位于左半圆，所以 `cos 120°` 一定为负。

## 正弦与余弦其实是同一段运动

- `cos x = sin(x + π/2)`：正弦图像向左平移 `π/2` 后与余弦重合。
- `sin x = cos(x - π/2)`：余弦图像向右平移 `π/2` 后与正弦重合。
- 两者周期、值域和波形形状相同，差别主要是开始记录时所处的位置不同。
- 单位圆上的恒等式 `sin²x + cos²x = 1` 来自点 P 始终满足圆方程 `横坐标² + 纵坐标² = 1`。

## 余弦函数的完整图像信息

- 定义域是全体实数，值域是 `[-1, 1]`。
- 最小正周期是 `2π`。
- 图像关于 y 轴对称，因此 `cos(-x) = cos x`，余弦是偶函数。
- 最大值出现在 `x = 2kπ`，最小值出现在 `x = π + 2kπ`。
- 零点出现在 `x = π/2 + kπ`。

## 最容易混的地方

- 正弦和余弦的图像形状很像，但起点不同。
- 如果只背曲线不看单位圆，最容易把关键点顺序记乱。
- “余弦为正”不是由角度大小决定，而是由终边落在左半圆还是右半圆决定。
- `cos(x + π/2)` 不等于 `cos x + π/2`。括号里的变化先作用于输入角，不是对函数值直接加数。

## 常见问题与解答

### 为什么余弦是偶函数

角 x 和角 -x 关于 x 轴对称。两个对应点的纵坐标相反，但横坐标相同；余弦只看横坐标，所以 `cos(-x) = cos x`。

### 为什么 `cos x = 0` 时点不在原点

`cos x = 0` 只说明横坐标为 0。单位圆上的点仍在圆周上，只能是 `(0, 1)` 或 `(0, -1)`，而不是圆心 `(0, 0)`。

### 已知 `sin x` 能直接求 `cos x` 吗

由 `sin²x + cos²x = 1` 可以求出 `|cos x|`，但正负还要看 x 所在象限。只开平方而不判断象限，是高频错误。

### 正弦和余弦谁“领先”谁

从 x = 0 开始，余弦已经在最大值 1，而正弦还在 0；可以说余弦比正弦提前 `π/2` 到达相同状态。用平移公式描述比只说“领先”更准确。
