## 这个知识点在解决什么

- 看懂 `tan x = sin x / cos x` 的单位圆来源
- 看懂正切函数为什么会出现断点
- 看懂一个周期为什么变成了 `π`
- 看懂靠近渐近线时图像为什么会越来越陡

## 单元定位

正切函数的核心不是先背图像，而是先看比值。单位圆上点 P 的纵坐标是 `sin x`，横坐标是 `cos x`，所以 `tan x = sin x / cos x`。只要分母接近 0，这个比值就会剧烈增大；分母等于 0 时，正切没有定义。

交互区把这个比值、单位圆右侧的切线段、红色渐近线和函数分支放在同一画面中。先选择“逼近断点 89°”，再选择“断点 90°”，比较“数值很大”和“没有定义”的根本区别。

## 正切先盯住三个点

- `断点`
  当余弦值为 0 时，正切没有定义，所以图像会在这些位置断开。
- 渐近线附近的陡升陡降
  这不是图像“画坏了”，而是函数值会迅速变得很大。
- 一个周期是 `π`
  因为转过半圈后，正切值的变化模式就已经重复。

## 为什么转半圈就重复

角 x 增加 π 后，单位圆上的点走到关于原点对称的位置，横、纵坐标同时变号：

- `sin(x + π) = -sin x`
- `cos(x + π) = -cos x`
- 两个负号在比值中抵消，所以 `tan(x + π) = tan x`

因此正切的最小正周期是 `π`，比正弦、余弦的 `2π` 少一半。

## 定义域和渐近线必须一起看

- 当 `cos x = 0` 时，x 满足 `x = π/2 + kπ`，这些输入必须从定义域中排除。
- 图像在这些位置画竖直虚线，称为竖直渐近线。
- “渐近”表示可以无限靠近，但函数图像不会碰到、穿过或沿着渐近线继续。
- 渐近线左侧趋向正无穷还是负无穷，要结合分子、分母的符号判断，不能只看距离。

## 每一支曲线为什么都递增

在区间 `(-π/2, π/2)` 内，角从左向右增大时，正切值从很小的负数不断增大，经过原点后继续增大到很大的正数。其他分支只是把这一支水平平移 kπ 得到，因此每个连续区间内都保持递增。

这里的“递增”只在每一个连续分支内讨论。不能拿渐近线左边的巨大正值和右边的巨大负值比较，然后说整个定义域上不递增；跨过断点比较不属于同一个连续区间。

## 正切的符号怎样判断

- 第一象限：sin、cos 都为正，所以 tan 为正。
- 第二象限：sin 正、cos 负，所以 tan 为负。
- 第三象限：sin、cos 都为负，所以 tan 为正。
- 第四象限：sin 负、cos 正，所以 tan 为负。
- 可概括为“正切一三象限为正，二四象限为负”，但要知道本质是两个坐标的比值。

## 读图时别忘了定义域

- 正切不是处处都有值。
- 先找哪些角不能取，再看单调区间和周期，会比直接背结论稳得多。
- 正切值没有最大值和最小值，值域是全体实数。
- 图像经过原点，并在每个分支中穿过一个零点 `x = kπ`。
- 正切是奇函数，`tan(-x) = -tan x`，图像关于原点对称。

## 最容易犯的四个错误

- 把“无定义”写成“等于无穷大”。无穷大不是这里的函数值；在断点处根本没有对应输出。
- 把渐近线两侧的曲线连起来。这样会错误地给断点补上函数值。
- 认为正切周期也是 `2π`。`2π` 当然也是周期，但最小正周期是 `π`。
- 看到每一支都递增，就写“正切函数在整个定义域上递增”。正确说法要限定在每个区间 `(-π/2 + kπ, π/2 + kπ)` 内。

## 常见问题与解答

### `tan 90°` 到底是多少

没有定义。因为 `cos 90° = 0`，而除数不能为 0。计算器出现错误提示，正是在执行这个定义域限制。

### 为什么 89.9° 的正切很大，却仍然有值

此时余弦只是非常接近 0，并没有等于 0。一个非零但很小的数作分母，会得到绝对值很大的比值；到 90° 时分母真正成为 0，函数值才消失。

### 正切图像为什么经过原点

`tan 0 = sin 0 / cos 0 = 0/1 = 0`，因此点 `(0, 0)` 在图像上。更一般地，`x = kπ` 时正弦为 0、余弦不为 0，所以都是零点。

### 改成 `tan(ωx)` 后什么会变

周期变成 `π/|ω|`，渐近线位置变成 `x = (π/2 + kπ)/ω`。ω 越大，分支和渐近线在水平方向排得越密。
