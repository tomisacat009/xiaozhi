## 这个知识点在解决什么

- 看懂 A 决定振幅、翻转和纵向伸缩
- 看懂 ω 决定周期与横向疏密
- 看懂 φ 和 d 分别控制左右位置、上下中线
- 能从图像反推 `y = A sin(ωx + φ) + d` 的关键参数

## 单元定位

这个单元承接标准正弦图像，研究一般形式 `y = A sin(ωx + φ) + d`。参数多并不意味着要同时猜四件事。最稳的方法是把它们分成“纵向”和“横向”两组，再按固定顺序读取。

交互区始终保留浅色的 `y = sin x` 作为参照。每次只拖动一个参数，观察单位圆实际转角、波形、中线、振幅带和当前函数值分别发生什么变化。

## 先用一张参数地图分工

- `A` 在函数外面，主要控制纵向：振幅是 `|A|`，A 为负时还会关于中线翻转。
- `ω` 乘在 x 前面，主要控制横向：周期是 `T = 2π/|ω|`。
- `φ` 加在括号里面，改变圆周运动的起始状态；水平平移量是 `-φ/ω`。
- `d` 加在函数外面，控制中线 `y = d`，使整条图像上移或下移。
- x 是当前观察位置；真正送进正弦函数的角不是 x，而是 `ωx + φ`。

## A：振幅、伸缩与翻转

- 当 `A = 2`，波峰到中线的距离由 1 变成 2，波谷也对称地拉远。
- 当 `0 < A < 1`，图像向中线压缩，但周期不变。
- 当 `A < 0`，先按 `|A|` 决定振幅，再把图像关于中线翻转。
- 当 `A = 0`，所有起伏消失，函数退化为常函数 `y = d`。此时谈“振幅为 0”可以，但不再有波峰和波谷。
- 若从图像读 A，先用 `(最大值 - 最小值) / 2` 求 `|A|`，再根据起点附近的变化方向判断符号。

## ω：周期不是直接等于参数

- 标准正弦完成一次循环，需要内部角增加 `2π`。
- 对 `sin(ωx)` 来说，x 只需增加 `2π/|ω|` 就能让内部角增加 `2π`。
- 因此 `T = 2π/|ω|`。ω 变大，周期变小，图像横向压缩；ω 变小，周期变大，图像横向拉伸。
- 高频错误是把 ω 直接当成周期。比如 `ω = 2` 时周期不是 2，而是 π。

## φ：先合并括号，再判断方向

把 `ωx + φ` 提取 ω：`ωx + φ = ω(x + φ/ω)`。因此图像相对标准位置的水平平移量是 `-φ/ω`。

- `φ > 0` 时，若 ω > 0，通常向左平移，而不是向右。
- `φ < 0` 时，若 ω > 0，通常向右平移。
- 不能只看 φ 判断移动距离，还必须除以 ω。
- 例如 `sin(2x + π)` 应先写成 `sin[2(x + π/2)]`，所以向左平移 `π/2`，不是 π。

## d：找到新的中线和值域

- `d > 0` 时整条图像上移，`d < 0` 时整条图像下移。
- 中线从 `y = 0` 变为 `y = d`。
- 最大值是 `d + |A|`，最小值是 `d - |A|`。
- 值域是 `[d - |A|, d + |A|]`。
- d 不改变振幅和周期，只改变整体高度。

## 从图像反推解析式的固定顺序

- 第一步：找最高点和最低点。中线 `d = (最大值 + 最小值) / 2`。
- 第二步：求振幅。`|A| = (最大值 - 最小值) / 2`。
- 第三步：量一个完整重复的水平长度得到周期 T，再算 `|ω| = 2π/T`。
- 第四步：找一个最熟悉的基准点，例如沿中线向上穿过的位置，判断水平平移。
- 第五步：把一个明显点代回解析式核对，避免 A 的符号或相位方向写反。

## 组合变换时怎样避免混乱

观察效果时可以按“基本正弦 → 横向变化 → 纵向变化”理解；实际计算关键点时，更推荐直接令内部角 `u = ωx + φ`，让 u 依次取 `0、π/2、π、3π/2、2π`，再解出对应的 x，并计算 y。

这种方法不会被“先平移还是先伸缩”的语言顺序绕晕，也能直接得到一个周期内的五个骨架点。

## 最容易犯的五个错误

- 把振幅写成 A。A 可能为负，但振幅作为距离应是 `|A|`。
- 把周期写成 `2π/ω` 却忘了 ω 可能为负。完整写法是 `2π/|ω|`。
- 看到 `+φ` 就说向右平移。括号内方向相反，且距离要看 `-φ/ω`。
- 把 d 当成最大值。d 是中线，最大值还要加 `|A|`。
- 同时拖动所有参数后只凭视觉猜结论。学习阶段应一次只改变一个量，先建立单变量因果关系。

## 常见问题与解答

### A 变大为什么不会改变周期

A 只放大或缩小每个输入对应的输出值，并没有改变内部角 `ωx + φ` 增长的速度，所以完成一轮循环所需的 x 长度不变。

### φ 和“初相”是什么关系

当 x = 0 时，送入正弦的内部角是 φ，所以 φ 描述运动在起点已经走到哪个状态。把它换成图像语言，就表现为水平位置改变。

### 同一条曲线为什么能写出不同形式

三角函数具有周期性，例如在 φ 上加 `2π` 不会改变正弦值；A 的负号也可以通过相位增加 π 来吸收。因此解析式可能不唯一，题目通常会限制 A、ω、φ 的取值范围以得到规范答案。

### 怎样判断参数是否写对

至少核对四件事：中线是否正确、最大最小值是否正确、周期是否正确、一个关键点及其变化方向是否正确。只核对某一个点，常常无法发现相位或 A 符号的错误。
