## 这个知识点在解决什么

- 看懂圆上的高度就是 `sin(x)`
- 建立角度制、弧度制与单位圆转角的对应
- 看懂一个周期为什么是 `2π`
- 会用象限判断正弦值的正负
- 看懂波峰、波谷和过零点怎样从圆周运动中出现

## 单元定位

很多同学第一次学三角函数，会把 `sin(x)` 当成一条需要硬背的曲线。这个单元要做的是把“角在转、点在动、高度在变、图像在记录”连成一个完整画面。

先拖动交互区的角度滑块，再点击“播放一圈”。观察圆上点的纵坐标、当前正弦值和右侧图像标记是否始终一致。只要这条联系建立起来，周期、符号、最值和图像都不再是零散结论。

## 先把角和弧度说清楚

- 角度制用 `°` 表示转了多少度，例如一周是 `360°`。
- 弧度制用弧长与半径的比来度量角。单位圆半径是 1，所以转过的弧长数值就是弧度数。
- 一周对应 `360° = 2π rad`，半周对应 `180° = π rad`，四分之一周对应 `90° = π/2 rad`。
- 高中函数式里的自变量默认按弧度理解。计算器若处在角度模式，直接输入 `sin(π/6)` 会得到错误结果。

## 先看单位圆怎么投到图像上

- 关注 `终边上的点`
  角度变化时，单位圆上对应点的纵坐标会连续变化，这个纵坐标就是 `sin(x)`。
- 单位圆上的点记作 `P(cos x, sin x)`
  横坐标是余弦，纵坐标是正弦。正弦值始终在 `-1` 到 `1` 之间，因为单位圆上的高度不可能超过半径 1。
- 波形不是凭空出现的
  它是把圆上一圈运动的高度，按角度顺序一格一格记录下来形成的。
- 一个周期是 `2π`
  因为单位圆转满一圈回到原位，正弦值的变化模式也完整重复一次。

## 关键角怎样生成五个骨架点

- `x = 0`：点在最右端，高度为 0，所以 `sin 0 = 0`。
- `x = π/2`：点到达最高处，高度为 1，所以 `sin(π/2) = 1`。
- `x = π`：点到最左端，高度回到 0，所以 `sin π = 0`。
- `x = 3π/2`：点到达最低处，高度为 -1，所以 `sin(3π/2) = -1`。
- `x = 2π`：点转回起点，高度再次为 0，一个周期完成。

画正弦图像时，先确定这五个点，再用平滑曲线连接，比凭印象画一条波浪线可靠得多。

## 用象限判断正负，不靠死记

- 第一、第二象限都在 x 轴上方，所以 `sin x > 0`。
- 第三、第四象限都在 x 轴下方，所以 `sin x < 0`。
- 终边落在 x 轴上时，纵坐标为 0，所以正弦值为 0。
- 判断 `sin 200°` 时，不必先算小数。200° 在第三象限，点在 x 轴下方，因此结果一定为负。

## 读图时先抓关键点

- 定义域是全体实数，任何实数角都能在单位圆上找到终边。
- 值域是 `[-1, 1]`，最大值 1、最小值 -1。
- 最小正周期是 `2π`，即 `sin(x + 2kπ) = sin x`。
- 图像关于原点对称，因此 `sin(-x) = -sin x`，正弦是奇函数。
- 零点、最大值点、最小值点最值得先抓。这些骨架一稳，后面看振幅、周期和相位会轻松很多。

## 最容易犯的四个错误

- 把 `sin x` 理解成 `sin × x`。`sin` 是函数名称，`sin x` 表示把 x 作为输入得到一个函数值。
- 混用角度和弧度。`sin 30° = 1/2`，但 `sin 30` 默认是 30 弧度，二者不是同一个数。
- 认为周期函数会不断重复函数值，所以不是函数。函数允许不同输入得到相同输出，只要求一个输入不能对应多个输出。
- 只背“正弦一二象限为正”。真正原因是正弦等于纵坐标，上半圆为正、下半圆为负。

## 常见问题与解答

### 为什么 `sin x` 的图像不是圆

单位圆负责提供每个角对应的高度；函数图像的横轴记录角 x，纵轴记录高度 `sin x`。横轴含义已经从圆上的横坐标变成了“输入角”，因此展开后是波形而不是圆。

### 为什么 `sin 390° = sin 30°`

390° 比 30° 多转了一整圈。终边位置完全相同，单位圆上对应点也相同，所以纵坐标相同。这就是周期性的几何来源。

### `sin x = 1/2` 为什么不只有 `x = π/6`

单位圆上高度为 1/2 的点在第一、第二象限各有一个，而且每转一整圈还会重复。因此在一个周期内有两个解，推广后还要加上整周期。

### 负角怎样理解

约定逆时针为正方向，顺时针为负方向。比如 `-π/2` 表示从正 x 轴顺时针转四分之一圈，对应最低点，所以正弦值为 -1。
