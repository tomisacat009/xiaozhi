## 这个知识点在解决什么

- 理解“匀变速”匀在哪里，而不是把它误认为速度不变
- 区分位置、位移、速度、速率与加速度
- 看懂 `x-t、v-t、a-t` 图像中的斜率、面积和弯曲方向
- 理解相同时间间隔内位移为什么按固定差值变化
- 把五条常用公式看成同一个运动过程的不同表达
- 会处理加速、减速、停止、反向、刹车和退化为匀速等典型情况

## 单元定位

匀变速直线运动是高中物理第一次集中出现多条公式、多个图像和大量正负号的章节。很多同学会背 `v=v0+at`，却说不清加速度为什么是 `v-t` 图的斜率，也不知道图像面积为什么会成为位移。

本单元把真实运动、打点计时器纸带、相等时间内的位移、`x-t、v-t、a-t` 三张图和公式推导放在同一个实验室里。播放动画时，同一条时间探针会同时穿过三张图，纸带上的小车、当前速度、累计位移和图像面积一起变化。

先选择“从静止开始 1:3:5”观察等时位移，再选择“先减速再反向”观察速度过零。不要急着背结论，先看运动过程如何生成图像和公式。

## 第一件事：先规定正方向

直线运动只有一条空间方向，但它有正、负两个朝向。解题前必须先规定正方向，例如“向右为正”或“竖直向下为正”。

- 位置 x 是物体在坐标轴上的坐标，可以为正、为负或为 0。
- 位移 `Δx=x-x0` 是末位置减初位置，是有方向的变化量。
- 速度 v 的正负表示运动方向；`v>0` 向正方向，`v<0` 向负方向。
- 速率是速度的大小 `|v|`，永远不为负。
- 加速度 a 的正负只表示加速度方向，不直接表示加速或减速。

同一题中一旦规定正方向，所有位置、位移、速度和加速度都要遵守同一套符号。中途随意改变正方向，是运动学计算出错的常见原因。

## “匀变速”到底匀在哪里

匀变速直线运动的严格含义是：加速度大小和方向都保持不变。

由加速度定义：

`a = Δv / Δt`

当 a 恒定时，在任意相等时间 `Δt` 内，速度变化量 `Δv=aΔt` 都相等。

所以“匀”的是速度变化的节奏，不是速度本身。速度每秒增加 2 m/s 和每秒减少 2 m/s 都属于匀变速运动；速度始终不变则是 a=0 的特殊情况，也就是匀速运动。

## 加速还是减速，要比较方向

判断物体“越来越快”还是“越来越慢”，要比较 v 与 a 的方向：

- v 与 a 同号：速度与加速度同向，速率增大，物体加速。
- v 与 a 异号：速度与加速度反向，速率减小，物体减速。
- `v=0、a≠0`：物体可能正处在开始运动或转向的瞬间。
- `a=0`：速度保持不变，退化为匀速直线运动。

例如，向右规定为正时，`v=-3 m/s、a=-1 m/s²` 表示物体向左运动且越来越快。虽然 a 是负数，但这仍然是加速运动。

## 五条核心公式来自同一个过程

以下公式只适用于加速度恒定的直线运动。式中的 x 是位置，`Δx=x-x0` 是位移；有些教材把位移写成 s。

### 速度公式

`v = v0 + at`

它来自 `a=(v-v0)/t`。含义是：末速度等于初速度加上这段时间内的速度变化量。

常用变形：

- `a=(v-v0)/t`
- `t=(v-v0)/a`，使用时要求 `a≠0`
- `v0=v-at`

### 位移公式

`s = s0 + v0t + 1/2 at^2`

若用位置和位移区分得更严格，可以写成：

`x = x0 + v0t + 1/2 at²`

`Δx = v0t + 1/2 at²`

其中 `v0t` 是按初速度保持不变时本会产生的位移，`1/2 at²` 是加速度额外带来的位移变化。

如果已知末速度 v，也可以写成：

`Δx = vt - 1/2 at²`

### 平均速度公式

匀变速直线运动的速度随时间线性变化，因此一段时间内的平均速度是初末速度的算术平均：

`v平均 = (v0+v)/2`

于是位移还可以写成：

`Δx = v平均 t = (v0+v)t/2`

这正是 `v-t` 图中梯形面积的计算公式。

### 速度—位移公式

把速度公式中的时间消去，可以得到：

`v^2 - v0^2 = 2a(s - s0)`

也就是：

`v²-v0²=2aΔx`

当题目给出初末速度、加速度和位移，却没有时间时，这条公式通常最直接。

常用变形：

- `v²=v0²+2aΔx`
- `Δx=(v²-v0²)/(2a)`
- `a=(v²-v0²)/(2Δx)`

### 中间时刻速度

因为速度随时间均匀变化，在一段时间的中间时刻：

`v(t/2)=(v0+v)/2=v平均`

注意这是“中间时刻”的速度，不是“中间位置”的速度。两者通常不相同。

## 三张图怎样共同描述同一运动

### `x-t` 图：斜率代表速度

`x-t` 图的纵坐标是位置，横坐标是时间。

- 某一点切线的斜率等于该时刻的瞬时速度。
- 图像向上倾斜表示 `v>0`，向下倾斜表示 `v<0`。
- 图像越来越陡表示速率越来越大，越来越平表示速率越来越小。
- 匀变速运动的 `x-t` 图通常是抛物线的一部分。
- a 为正时图像整体“向上弯”，a 为负时整体“向下弯”。
- 顶点处切线水平，对应速度 `v=0`，可能是转向时刻。

`x-t` 图下方的几何面积通常没有直接运动学含义。不要把所有运动图像都机械地套用“面积等于位移”。

### `v-t` 图：斜率代表加速度，面积代表位移

匀变速运动满足 `v=v0+at`，所以 `v-t` 图是一条直线。

- 斜率 `Δv/Δt` 等于加速度 a。
- 直线越陡，`|a|` 越大。
- 图线与时间轴之间的有向面积等于位移。
- 时间轴上方的面积为正位移，下方的面积为负位移。
- 图线穿过时间轴表示速度经过 0，物体可能改变运动方向。
- 图线离时间轴的距离表示速率大小。

如果图像一部分在时间轴上方、一部分在下方，求总位移时要把面积带符号相加；求路程时则要把各部分面积的绝对值相加。

### `a-t` 图：面积代表速度变化量

匀变速运动的 a 恒定，因此 `a-t` 图是一条水平线。

- 水平线的高度表示加速度大小和方向。
- 图线与时间轴围成的有向面积 `at` 等于速度变化量 `Δv`。
- a 在时间轴上方，速度按固定节奏增加；a 在下方，速度按固定节奏减小。
- `a=0` 时图线与时间轴重合，但物体不一定静止，它可能保持非零速度做匀速运动。

## 图像之间怎样互相转换

把三张图串起来，可以形成一条稳定的关系链：

- `x-t` 图在每一时刻的斜率，组成 `v-t` 图。
- `v-t` 图在每一时刻的斜率，组成 `a-t` 图。
- `a-t` 图从 0 到 t 的面积，给出 `v-v0`。
- `v-t` 图从 0 到 t 的面积，给出 `x-x0`。

可以把它记成：向下看图像时看“斜率”，向上还原时看“面积”。

## 相同时间内的位移为什么越来越有规律

打点计时器每隔相同时间打一个点。纸带上相邻点之间的距离，就是物体在相等时间内的位移。

设每段时间都是 `Δt`，第 n 个时间段是从 `(n-1)Δt` 到 `nΔt`。第 n 段位移为：

`Δx_n = v0Δt + 1/2 a(2n-1)(Δt)²`

相邻两段相减：

`Δx_(n+1)-Δx_n = a(Δt)²`

因此在匀变速直线运动中，相邻相等时间内的位移差是一个恒量。这叫逐差规律，是处理纸带实验和判断是否匀变速的重要依据。

### 每秒内位移公式

当 `Δt=1 s` 时，第 n 秒内的位移为：

`Δx_n = v0 + a(n-1/2)`

这里“第 n 秒内”是一段时间，指从 `n-1` 秒末到 n 秒末；它和“n 秒末”这个时刻完全不同。

### 从静止开始时的 1:3:5:7 规律

若 `v0=0`，则每个相等时间段内的位移正比于：

`1:3:5:7:…:(2n-1)`

例如从静止开始做匀加速运动，前四个 1 秒内的位移之比是 `1:3:5:7`。

同时，从开始到第 1、2、3、4 个相等时间末的总位移之比为：

`1²:2²:3²:4² = 1:4:9:16`

不要把“每段位移比 1:3:5”和“累计位移比 1:4:9”混在一起。

### 逐差法求加速度

由 `Δx_(n+1)-Δx_n=a(Δt)²` 可得：

`a=[Δx_(n+1)-Δx_n]/(Δt)²`

实验数据存在误差时，通常不会只拿相邻两段计算，而会把较远的两组位移做差再平均，以充分利用纸带数据、减小偶然误差。

## 常见题型如何选公式

不要从五条公式中盲猜。先列出题目已知量和未知量，再选择不含多余未知量的公式。

- 已知 `v0、a、t` 求 v：用 `v=v0+at`。
- 已知 `v0、a、t` 求位移：用 `Δx=v0t+1/2at²`。
- 已知 `v0、v、t` 求位移：用 `Δx=(v0+v)t/2`。
- 已知 `v0、v、a` 求位移：用 `v²-v0²=2aΔx`。
- 已知 `v0、v、Δx` 求加速度：用 `a=(v²-v0²)/(2Δx)`。
- 已知图像：优先从斜率、截距和面积读取，不必先套代数公式。

## 刹车问题

车辆以初速度 v0 做匀减速运动，若规定初速度方向为正，则加速度 a 为负。

停车时间由 `0=v0+at` 得：

`t停=-v0/a=v0/|a|`

刹车距离由 `0-v0²=2aΔx` 得：

`Δx停=v0²/(2|a|)`

刹车题最常见的陷阱是题目给出的时间超过停车时间。现实中的车停下后不会自动反向倒车；若题意是“刹车直到停止”，计算必须在停车时刻截断，后续位移保持不变。

而在纯数学模型 a 始终保持不变的情况下，物体速度过零后会反向运动。是否继续反向，要根据实际情境判断。

## 先减速再反向怎样看

当 v 与 a 反向时，物体先减速。速度达到 0 的时刻为：

`t转=-v0/a`

若加速度继续保持不变：

1. 转向前，速度绝对值逐渐减小；
2. 转向瞬间，`v=0`，但通常 `a≠0`；
3. 转向后，v 与 a 变为同向，物体沿反方向加速。

在 `x-t` 图上，转向点是切线水平的顶点；在 `v-t` 图上，它是直线与时间轴的交点。

## 位置、位移和路程不能混用

假设物体从 `x0=2 m` 出发，先运动到 `x=8 m`，再返回 `x=5 m`：

- 末位置是 5 m；
- 总位移是 `5-2=3 m`；
- 总路程是 `6+3=9 m`。

位移只看起点和终点，路程要把实际经过的各段长度全部相加。只有物体始终不改变运动方向时，路程才等于位移的绝对值。

## 怎样使用同步实验室

### 观察正向匀加速

选择“正向匀加速”，播放全过程：

- 纸带点间距越来越大；
- `x-t` 图切线越来越陡；
- `v-t` 图沿直线上升，斜率保持不变；
- `a-t` 图保持水平；
- 每段位移卡的差值相同。

### 观察从静止开始

选择“从静止开始 1:3:5”，将等时间隔设为 1 s。比较前几段位移，验证 `1:3:5:7`；再看累计位置，验证 `1:4:9:16`。

### 观察先减速再反向

选择“先减速再反向”，让时间探针经过速度为 0 的时刻：

- `v-t` 图穿过时间轴；
- `x-t` 图在同一时刻出现水平切线；
- 纸带点先变密，再向相反方向展开；
- 图像面积开始出现正负抵消，总位移可能减小。

### 只改一个参数

- 改 x0：只改变位置图的整体高度，不改变速度和加速度。
- 改 v0：改变 `v-t` 图的纵截距，也改变位置图初始斜率。
- 改 a：改变 `v-t` 图斜率、`x-t` 图弯曲方向和相邻等时位移差。
- 改观察时刻 t：只移动同步探针，不改变完整运动模型。
- 改 `Δt`：改变纸带取样密度，固定差值按 `a(Δt)²` 变化。

## 最容易犯的十个错误

- 把“匀变速”理解成速度不变；实际恒定的是加速度。
- 只看 a 的正负判断加速减速，没有比较 v 与 a 的方向。
- 把位置 x 直接当成位移，忘记减去初位置 x0。
- 把速度负数误认为“速度大小为负”；负号表示方向。
- 把 `x-t` 图的纵坐标当成物体真实运动轨迹。
- 认为所有图像下的面积都有位移含义；只有 `v-t` 图面积直接表示位移。
- 求 `v-t` 图面积时忽略时间轴下方区域应取负号。
- 把“第 3 秒内”与“3 秒末”混为一谈。
- 在刹车题中越过停车时刻继续套匀减速公式，算出车辆反向。
- 只背 `1:3:5`，却忘记它要求从静止开始且时间间隔相等。

## 常见问题与解答

### 加速度为 0，物体一定静止吗

不一定。a=0 只说明速度不再变化。如果初速度不为 0，物体会保持这个速度做匀速直线运动；只有速度也为 0 时才静止。

### 速度为 0，加速度一定为 0 吗

不一定。物体竖直上抛到最高点时速度瞬间为 0，但重力加速度仍然存在；先减速再反向的模型在转向瞬间也是如此。

### `v-t` 图在时间轴下方，物体的位置一定为负吗

不一定。时间轴下方只表示速度为负、物体向负方向运动。物体的位置取决于初位置和之前累计的位移，仍可能位于正坐标区域。

### `x-t` 图向下弯，物体一定向负方向运动吗

不一定。向下弯表示加速度为负；运动方向要看切线斜率，也就是速度的正负。图像可能仍向上倾斜，只是越来越平，此时物体向正方向减速。

### 平均速度为什么等于初末速度平均值

这一结论依赖速度随时间线性变化。`v-t` 图是一条直线，梯形面积既可写为位移，也可写成“平均高度 × 时间”，平均高度正是 `(v0+v)/2`。非匀变速运动不能直接使用这一结论。

### 纸带点越来越密说明什么

相同时间内的位移越来越小，说明速率在减小。如果点间距减到 0 后又向相反方向展开，说明物体发生了转向。

### 为什么逐差规律与初速度无关

初速度会给每个相等时间段都增加同样的基础位移 `v0Δt`。相邻两段相减时，这部分正好抵消，只剩下加速度产生的 `a(Δt)²`。

### 路程能不能直接用 `v-t` 图有向面积求

如果速度始终同号，可以。若速度跨过 0，就要把时间轴上方和下方的面积绝对值分别相加；直接带符号相加得到的是位移，不是路程。

## 最后形成一张关系图

- 加速度恒定 → 相等时间内速度变化量相等。
- 速度随时间线性变化 → `v-t` 图是直线。
- 速度不断累积成位移 → `x-t` 图是抛物线的一部分。
- `x-t` 斜率 → 速度。
- `v-t` 斜率 → 加速度；`v-t` 面积 → 位移。
- `a-t` 面积 → 速度变化量。
- 相邻等时位移差 → `a(Δt)²`。
- 从静止开始 → 分段位移比 `1:3:5:7…`，累计位移比 `1:4:9:16…`。
- 判断加速减速 → 比较 v 和 a 的方向。

真正掌握匀变速运动，不是记住最多的公式，而是能够在运动现场、纸带、图像和代数式之间自由翻译。
